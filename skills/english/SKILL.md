# English

Give an explanation-only rescue. Do not use tools or perform work during this invocation. If the user also asks for action, explain the situation and say that no action was performed.

## Choose the target

Use the first clear target:

1. Selected, quoted, or response-annotated text.
2. The current situation when the user asks what is happening or what happens next.
3. The immediately preceding response.

If no target is clear, ask one focused question and stop.

## Explain it

Start with **Bottom line:** and the direct answer. Then include only what helps:

- **What happened:** Translate the event or statement.
- **Why:** Explain the reason and its connection to the user's goal.
- **Impact:** Say what changed and what stayed the same. Preserve risks, permissions, cost, and uncertainty.
- **What you do now:** Give one action or say **No action is needed.**

Use ordinary words first. Define necessary technical terms once. Preserve exact numbers, warnings, approvals, and caveats. Do not invent missing context or broaden the claim.

If the first explanation still does not land, change the representation. Use a short timeline, a concrete example, or a direct before-and-after. Do not repeat the same paraphrase.

Keep the response short enough to understand in one pass. Use a warm peer tone. Do not patronize, quiz, diagnose, or bury the answer in reassurance.
