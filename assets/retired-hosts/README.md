# Retired host artwork

Cursor/Grok Bot and ZCode support ended in September 2026. These folders preserve every packaged
artwork file from their removed adapters, with the former path below `adapters/` retained here.
They contain no active skills or plugin manifests.

`manifest.json` records each archived file's SHA-256 fingerprint. Keep these files unchanged.
Canonical plugin and skill artwork remains under `assets/plugins/` and `skills/*/assets/`.
